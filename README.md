# SimZoo

Projeto desenvolvido em Java para a disciplina de Programação Orientada a Objetos, da a Escola Técnica de Brasilia. 

## O SimZoo é um sistema de gerenciamento de animais de um zoológico utilizando conceitos de Programação Orientada a Objetos.

## Funcionalidades

- Cadastro de animais
- Classe abstrata `Animal`
- Herança
- Polimorfismo
- Classe `Especie`
- Cálculo de idade
- Uso de Lombok

## Tecnologias

- Java
- Lombok
- Git
- GitHub
- NetBeans
